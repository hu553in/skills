# GitHub metadata

Read live values for the repositories and fields in scope. For rulesets, check enforcement, targets,
bypass actors, and the rules and their parameters. Compare managed values with their source
manifest. When proposing changes, show the current and proposed value for each affected field.

Use concise taglines for descriptions and stable lowercase slugs for topics. Preserve homepage and
visibility unless the request covers them. Apply only authorized changes and read live values again
to verify the result.

## Tags and releases

Delete tags or releases only on explicit request. Verify the exact tags or releases on the intended
remote before and after deletion. Pause if the targets are ambiguous or differ from what the user
approved.
